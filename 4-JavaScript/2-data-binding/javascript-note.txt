
=> Variable in javascript?

=> Difference between var, let, const
    var, let, const use to create variable in javascript.
    let and const was introduced in 2015.

    Value change
        -> var allow to change the value
        -> let allow to change the value
        -> const do not allow to change value

    Re-Declaration
        -> var allow to re-declare
        -> let and const do not allow

    Scope of Variable
        -> var has global Scope
        -> let and const have block level scope able to access only within( ......)

    Events in javascript
        The Type of User interaction with UI Called event in javascript
        it is of following type
    1. Mouse Events
        ->onClick
        ->ondblclick
        ->onmousedown
        ->onmouseenter
        ->onmouseout
        ->onmousemove
        ->onchange

    2. Keyboard Events
        -> onkeypress
            1. It take previous value 
            2. backspace will not work
        -> onkeydown
            1. It take previous value 
            2. backspace will work
        ->onkeyup
            1. It take old + new value 
            2. backspace will work
        ->onfocus
            It takes old value as curser focus in element
        ->onblur
            It take old + new value as curser move out from element

    3. Body Events
     ->onload
    4. Form Events
     -> onsubmit -Will study at end of js with form validation
