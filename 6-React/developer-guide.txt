How to Setup react project
    create folder as react
    from terminal run
        1. npm install -g create-react-app

        2. npx create-react-app project1
How to start react development server
    -> Open cmd in project folder
    -> run the command
          npm start
    Inside that directory, you can run several commands:

      npm start
        Starts the development server.

      npm run build
        Bundles the app into static files for production.

      npm test
        Starts the test runner.

      npm run eject
        Removes this tool and copies build dependencies, configuration files
        and scripts into the app directory. If you do this, you can’t go back!

    We suggest that you begin by typing:

      cd project1
      npm start

      Note that the development build is not optimized.
    To create a production build, use npm run build.

  JSX - Javascript and XML (javascript + html + xml rules)

--------------------------------------------------------------------------------
  JSX Element - All the html tags + user defined tags are called jsx element in react

--------------------------------------------------------------------------------
  JSX Rules  (how to write react code)
  -> if inside a Component more than 1 jsx element are required then keep inside parent jsx element.
     example
      <div>
        <h1> Welcome To React </h1>
        <p> This is from p tag </p>
        <p> dfs dfscvcg ccdf ghjj jjkiiuuy</p>
      </div>

  -> The parent or child jsx element can be user defined tag also
    example
      <abc>
        <h1> Welcome To React </h1>
        <p> This is from p tag </p>
        <xyz> dfs dfscvcg ccdf ghjj jjkiiuuy</xyz>
      </abc>

  -> The parent or child jsx element can be <> </> tag also
    example
      <>
        <h1> Welcome To React </h1>
        <p> This is from p tag </p>
        <p> dfs dfscvcg ccdf ghjj jjkiiuuy</p>
      </>

   ->  The parent jsx element can be array [] also
      example
        [
          <h1> Welcome To React </h1>,
          <p> This is from p tag </p>,
          <p> empty tag added </p>
        ]
